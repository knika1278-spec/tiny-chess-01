A chess engine in under 4 KB of Python (standard library only): a 10x12 mailbox
move generator, negamax alpha-beta with quiescence search, null-move pruning,
transposition-table move ordering and piece-square tables. It searches a fixed
node budget per move and never reads a clock, so a replay plays the same moves.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
